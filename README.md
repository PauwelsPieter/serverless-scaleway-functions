# Extension on Scaleway plugin for Serverless Framework

Extension on plugin for using Scaleway [Serverless Functions](https://www.scaleway.com/en/serverless-functions/) and [Serverless Containers](https://www.scaleway.com/en/serverless-containers/) with [Serverless Framework](https://serverless.com/).

Original package can be found [here](https://github.com/scaleway/serverless-scaleway-functions).

## Why this package?

PR(s) opened on original package to include the following features:

- [Configure NATS triggers](https://github.com/scaleway/serverless-scaleway-functions/pull/255)
